# POCKET CIRCUIT / Kart Racer

青空と丘の **MEADOW LOOP** を、最大 8 台で走るオリジナルの 3D カートレース。1 人用（プレイヤー + CPU 7 台）と、オンライン対戦（最大 8 人、空いた枠は CPU）で、3 周の順位とタイムを競います。モデル・景色は手続き生成、音は WebAudio 合成で、外部画像・モデル・音声ファイルは使いません。

▶ **今すぐ遊ぶ: https://machaniconico.github.io/kart-racer/** （PC・スマホ対応。スマホは横画面で）

## 起動と開発

Node.js **22.12 以降**（22 LTS 推奨）を使用してください。

```sh
npm install
npm run dev
```

表示されたローカル URL の `/kart-racer/` を開きます。スマホからは同じ Wi-Fi に接続し、Vite の Network URL に `/kart-racer/` を付けてアクセスしてください。

```sh
npm run build       # strict TypeScript チェック + dist/ に本番ビルド
npm test            # Vitest を一度実行
npm run test:watch  # Vitest の監視実行
npm run typecheck   # 型チェックのみ
npm run preview    # ビルド済み dist/ を確認
npm run e2e         # オンライン対戦の E2E（Playwright。下記）
```

`npm run e2e` は 2 つのブラウザコンテキストで実際にルームを作って参加します。**公開の PeerJS ブローカー**を使うため、ブローカーの状態や回線によって不安定な場合があります。CI（`.github/workflows/e2e.yml`）では手動実行（`workflow_dispatch`）のみです。初回は `npx playwright install chromium` が必要です。

## 遊び方

### 1 人用

タイトルの「レースをはじめる」で 3・2・1 の後にスタート。プレイヤー 1 台と CPU 7 台で走ります。道路の外の芝は減速し、壁や他のカートに衝突すると速度や進路が変わります。チェックポイントを順番に通過して 3 周してください。逆走・チェックポイントの飛ばし・コースの瞬間移動では周回が成立しません。

### オンライン（最大 8 人）

1. **ホスト**: 「オンライン対戦」で「ルーム作成」を押し、表示されたルームコードを参加者に共有する（コピー / 共有ボタン）。
2. **ゲスト**: 「ルームコード」欄にコードを入れて参加する。
3. ロビーで名前（10 文字まで）とカートの色を選ぶ。
4. ホストが「スタート」を押すとレースが始まる。人数が 8 に満たない枠は CPU が走ります。

### つながらないとき

接続は P2P（ブラウザ同士の直接通信）です。一部の会社や学校のネットワーク、モバイル回線では、直接つながらないことがあります。**同じ Wi-Fi か、別の回線**で試してください。通信は PeerJS の既定設定で、PeerJS 既定の公開 STUN/TURN サーバを利用します（無償の公開サービスなので可用性は保証されません）。それでもつながらない環境があります。

### 制約

- **ホストは画面を閉じたり、アプリを切り替えたりしないでください。** ホストの画面が止まると全員のレースが止まります。iOS でホストが画面を離れて通信が止まると、次のどちらかで切断されます。ICE が `disconnected` の状態が 8 秒続いたとき。レース中にホストからのスナップショットが 5 秒止まったとき（ゲストはホスト喪失として扱います）。
- ホスト移譲、観戦、途中参加はありません。

### 操作

| 操作 | PC | スマホ | 標準ゲームパッド |
| --- | --- | --- | --- |
| ステア | ← → / A D | 左スティックを左右へ | 左スティック / 十字キー |
| アクセル | ↑ / W | アクセル、または AUTO 切替 | A / RT |
| ブレーキ | ↓ / S | ブレーキ | B / LT |
| ドリフト・ホップ | Space を押しながら曲がる | DRIFT を押しながら曲がる | X |
| アイテム | Shift / E | ITEM | RB / Y |
| 一時停止（1 人用のみ。オンラインでは退出の確認だけで、レースは止まらない） | Esc / 一時停止ボタン | 一時停止ボタン | 画面の一時停止ボタン |

ドリフトの火花が **水色（0.65 秒）→ オレンジ（1.5 秒）** に変化します。ドリフトを離すと、溜めた段階に応じてミニターボが発動します。

アイテム（トラップ・ボルト・ダミーボックス・ポップボム）は、ボタンを**押しっぱなしにすると後ろに構えて防御**し、**離すと発射**します。構えている間は、後ろから来たボルト・ボムを防げます（防ぐとアイテムを消費）。ダッシュ系・オーラ・ストーム・インクは押した瞬間に発動します。

### アイテム

アイテムボックスはコース上の 4 列・計 12 個。取得すると 5 秒で復活します。一度に持てるアイテムは 1 個で、順位によって出やすいものが変わります（上位は設置・基本系、下位は強力な加速・無敵系）。

| 名前 | 効果 |
| --- | --- |
| ソニックダッシュ | 約 1.9 秒の加速。 |
| ポップトラップ | 後方に置き、踏んだ相手をスピンさせる。一定時間後は自分も踏む。 |
| リコシェボルト | 前方へ直進（ブレーキを押しながらなら後方）。壁で反射し、4 回反射または寿命で消える。当たるとスピン。 |
| ハウンドボルト | 前方 45m 以内の上位カートを追尾する。壁では反射せず消える。命中でスピン。 |
| スカイコメット | コースに沿って、自分以外の未ゴールで最上位のカートを狙って飛び（自分が 1 位なら 2 位）、到達点の半径 4.5m 内の全員をスピンさせる。 |
| トリプルダッシュ | 1 回の使用で 1.4 秒ブースト、3 回まで使える。所持中はアイテムボックスを取れない。 |
| ブレイズダッシュ | 8 秒間、押すたびに 0.45 秒ブースト（連打）。 |
| シャインオーラ | 7 秒間、最高速 ×1.3、被弾無効、触れた相手をスピンさせる。 |
| スパークストーム | 自分以外の未ゴールのカート（シャインオーラ中・ロケットライド中を除く）を 5 秒間、縮小・最高速 ×0.65 にし、所持アイテムを奪う。 |
| インクスプラッシュ | 自分より上位でまだゴールしていない全員の画面を 4 秒間インクで覆う。 |
| ダミーボックス | トラップと同じく後方に置く。見た目はアイテムボックスで、踏むとスピン。 |
| ポップボム | 前方（ブレーキを押しながらで後方）へ投げ、2.5 秒または接近で爆発。半径 4.5m をスピンさせる（自分も含む）。 |
| ロケットライド | 4 秒間、自動運転で最高速 ×1.5、被弾無効、触れた相手をスピンさせる。 |
| オービットガード | 自分の周りを 3 個のトラップまたはボルトが周回し、触れた相手をスピンさせる（1 個消費）。使用で 1 個を前方に発射または後方に設置。 |

スマホは横画面推奨。ステアとドリフトなどの同時押しに対応し、タッチ端末では自動アクセルが初期 ON です。縦画面には横向きの案内を表示します。1 人用では、画面を離れた場合に自動で一時停止します（オンラインでは止まりません）。音は開始操作後に有効になり、右上のボタンでミュートできます。

ミュート設定と、1 人用のベストの合計タイムを `localStorage` に保存します（ベストはオンラインでは更新しません）。ストレージが利用できない場合もプレイできます。1 人用ではプレイヤーがゴールすると結果画面に移ります。オンラインでは自車がゴールしてもすぐには移らず、人間全員のゴールかタイムアウトを待ちます。結果画面では、未完走の車をその時点の進行順位で「走行中」と表示します（タイムアウトで終わった場合は「DNF · 未完走」）。

## 構成

```text
src/
  sim/        # three / DOM に依存しない固定 60 Hz のシミュレーション
    types.ts  # InputFrame、InputSource、JSON 保存可能な RaceState
    track.ts  # 閉じた Catmull-Rom スプライン、距離・路面投影
    race.ts   # 簡易物理、衝突、ドリフト、アイテム、レース進行
    laps.ts   # 方向付きチェックポイント、周回、順位
    ai.ts     # CPU の InputFrame 生成
    random.ts # seed 付き PRNG
    itemTable.ts # 順位別のアイテム抽選テーブル（8 位まで）
    sim.test.ts
  render/     # three のコース、カート、追従カメラ、火花
  input/      # キーボード・タッチ・Gamepad を InputFrame に変換
  audio/      # WebAudio のエンジン・ドリフト・効果音
  net/        # オンライン対戦: Transport 抽象、ホスト/ゲストのセッション、スナップショット codec、予測・補間、PeerJS 実装、ルームコード
  ui/         # タイトル、HUD、ミニマップ、結果、一時停止、LobbyUI（ルーム作成・参加・ロビー）、アイテムアイコン
  main.ts     # 固定ステップ実行、状態補間、各層の接続
  storage.ts  # 例外処理付きのベストタイム・ミュート保存
  style.css
.github/workflows/
  deploy.yml  # main への push で Pages に公開
  e2e.yml     # オンライン対戦 E2E（手動実行のみ）
e2e/          # Playwright（実 PeerJS ブローカー）
```

シミュレーションは `stepRace(state, inputs)` で 1 tick 進みます。`RaceState` に RNG 状態を含むため、同じ seed と tick ごとの `InputFrame[]` で再現できます。`JSON.parse(JSON.stringify(state))` したスナップショットからも継続可能です。CPU も入力を作るだけで、物理を直接上書きしません。ネットワーク入力もこの境界で差し替わります。

描画は前後のカート状態を補間し、シミュレーションを変更しません。木・岩・縁石・ガードレールなどはインスタンシング、カート本体はマテリアルごとに結合しています。影は directional light 1 灯、DPR は最大 2。`prefers-reduced-motion` 時はタイトルカメラの揺れや追従カメラのドリフト演出を抑えます。

開発サーバーでのみ `window.__kartDebug` から状態の参照と `advance(ticks, true)` による CPU 自動走行検証ができます。本番ビルドには含まれません。

## GitHub Pages

`vite.config.ts` の `base` は **`/kart-racer/`** です。GitHub リポジトリの Settings → Pages → Source を **GitHub Actions** に設定してください。`main` への push または workflow の手動実行で、`npm ci` → テスト → ビルド → `actions/deploy-pages` の順に公開します。リポジトリ名を変える場合は `base` も変更してください。

## 実装上の範囲

- コースは 1 つ。1 人用（CPU 戦）とオンライン対戦（最大 8 人、P2P、ホスト権威）。通信は PeerJS 既定の公開 STUN/TURN を利用します。
- 物理は平面上の簡易カート物理と路面の高さへの追従です。ホップは描画演出で、立体ジャンプや転倒は扱いません。
- 60fps は中級スマホでの目安です。実機・ブラウザ・電力設定によって性能とゲームパッドの割り当ては異なります。
- WebGL が利用できない場合は画面内に再読み込み案内を表示します。音声が許可されない場合もゲームは動作します。
